# Changelog

All notable changes to look are recorded here.

## 0.1.0 — in development

- Initial Windows WPF browser shell and WebView2 adapter.
- Per-tab browser controls, navigation, tab actions, and find-in-page.
- Local session, bookmark, history, recently-closed, and download metadata storage.
- Basic unpacked-extension management.
- Separate temporary profile and data directory for private windows.
- Portable-mode data location and Windows packaging scripts.

This is a development version. It has not yet passed a complete Windows release verification or extension compatibility test matrix.
