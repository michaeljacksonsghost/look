# Keyboard shortcuts

The following shortcuts are implemented in the current WPF shell. Some actions are scoped to the active Space.

| Shortcut | Action |
|---|---|
| `Ctrl+L` | Focus and select the address bar |
| `Ctrl+T` | Open a new tab |
| `Ctrl+W` | Close the active tab |
| `Ctrl+R` | Reload the active page |
| `Ctrl+F` | Open find in page |
| `Ctrl+Shift+N` | Open a private window using the current named profile's identity, but a separate temporary data store |
| `Ctrl+Shift+T` | Restore the most recently closed tab |
| `Ctrl+Shift+A` | Open the searchable tab switcher across Spaces |
| `Ctrl+Tab` | Move to the next tab in the active Space |
| `Ctrl+Shift+Tab` | Move to the previous tab in the active Space |
| `Ctrl+1`–`Ctrl+8` | Switch to tab 1–8 in the active Space |
| `Ctrl+9` | Switch to the last tab in the active Space |
| `Esc` | Close the tab switcher or exit the element picker; in-page find has its own close control |

These shortcuts have passed compilation but still need hands-on Windows keyboard testing. Future work includes a remappable shortcut settings page and a complete keyboard-only accessibility audit.
